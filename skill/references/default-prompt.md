# 會議記錄摘要撰寫指南

## 任務說明
您的任務是審閱所提供的會議音檔，並撰寫一份的完整的會議記錄。重點聚焦於：

* **關鍵要點 (Key Takeaways)**：會議的主要結論與決策
* **討論過程 (Meeting Details)**：依討論事件分別記錄各與會者的想法與立場
* **行動項目 (Action Items)**：指派給特定個人或部門的待辦事項
* **腦力激盪項目 (Brainstorm Items)**：討論過程沒有特別結論，但有來回討論並有一些想法的產出，這些是會議記錄中含金量很高的資訊，因此獨立一個區塊來記錄

---

## 撰寫規範

### 語言與格式
* 會議記錄使用**繁體中文 (#zh-tw)** 記錄
* 使用清晰、專業的語言
* 運用適當的格式元素組織內容：
    * 主標題與副標題
    * 項目符號列表
    * **粗體強調重點**
* 確保邏輯清晰、易於理解

### 內容要求
* 提供全面而簡潔的會議概述
* 討論過程以**議題/事件**為單位組織，在每個事件下清楚記錄各與會者的想法、立場與觀點
* 明確指出每個行動項目的**負責人**與**截止日期** (如有)
* 保留關鍵專案術語與縮寫
* 避免冗贅，聚焦核心訊息
